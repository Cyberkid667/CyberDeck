# Third-party data

CyberDeck ships the following data with the app. It is used **offline**: nothing is downloaded at run time, and peer addresses are never sent anywhere.

## IP to country: DB-IP "IP to Country Lite"

- File: `build/geo/ip-country.bin` (bundled into the app), generated by `scripts/make-geo.mjs` from `dbip-country-lite-2026-10.csv.gz`.
- Source: [IP Geolocation by DB-IP](https://db-ip.com), https://db-ip.com/db/download/ip-to-country-lite
- License: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- Changes: ranges merged when neighbouring ranges have the same country, IPv6 reduced to /48 prefixes, re-encoded as a compact binary table (Brotli). Country codes are unchanged.
- Use: the torrent engine looks up the country of each connected peer, to place it on the peers globe.

## Land mask and country positions: Natural Earth

- Files: `src/renderer/src/fx/landMask.ts` (land mask at 0.5°) and `src/shared/geoCentroids.ts` (one label point per country), generated by `scripts/make-geo.mjs` from Natural Earth 1:50m "Land" and "Admin 0 – Countries".
- Source: [Natural Earth](https://www.naturalearthdata.com), free vector and raster map data.
- License: public domain.
- A few small territories missing at 1:50m use the geographic coordinates of the CIA World Factbook (public domain).

## Regenerating

```bash
node scripts/make-geo.mjs dbip-country-lite-YYYY-MM.csv.gz ne_50m_land.geojson ne_50m_admin_0_countries.geojson
```
